# CleanUI-Classic

Minimalist layout addon for World of Warcraft Classic (1.15.x).

## What it does

| Area | Behaviour |
|---|---|
| **Action bars** | Repositions and reskins MainMenuBar, MultiBarBottomLeft/Right, MultiBarRight/Left, stance bar, and pet bar. Hides decorative chrome. |
| **Bags** | Anchors bag slots above the micro menu, stacks open container frames in two columns, and auto-opens bank bags. |
| **Micro menu** | Right-aligns all micro buttons along the screen edge at half opacity. |
| **LFG button** | Detaches the LFG button from the minimap and places it left of the micro menu. |
| **Cast bar** | Detaches the player cast bar from the player frame and centres it above the action bars — appearance unchanged. |
| **Auras** | Anchors buff frame to the top-left of the minimap; stacks debuffs below. |
| **Minimap** | Scales and repositions the minimap cluster to the top-right; hides decorative chrome and enables scroll-to-zoom. |
| **Status bars** | Reskins XP and reputation bars with a clean texture and dark background. Adds an XP tooltip on hover. |
| **Tooltips** | Anchors non-cursor tooltips to the top-left of the target frame. |
