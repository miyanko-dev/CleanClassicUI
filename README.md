# CleanUI Classic

Minimalist UI addon for World of Warcraft Classic Era (1.15.x).

## Features

- **Action Bars** — Clean bordered buttons, hidden chrome, centered layout with pet and stance bars
- **Bags** — Bordered bag buttons, stacked container frames, auto-open bank bags, toggle all with backpack
- **Micro Menu** — Right-aligned along the bottom screen edge
- **LFG Button** — Detached from minimap, placed left of the micro menu
- **Cast Bar** — Minimal bordered bar centered above action bars
- **Nameplates** — Pure health bar with tooltip-style border and threat coloring
- **Auras** — Bordered buffs/debuffs with color-coded debuff types, anchored near minimap
- **Minimap** — Enlarged, scroll-to-zoom, hidden decorative elements
- **Status Bars** — Reskinned XP/rep bars with border and hover tooltip
- **Chat** — Hidden side buttons, styled edit box, class-colored names
- **Raid Frames** — Custom bar texture, class colors, hidden border
- **World Map** — Scaled down, centered, fades while moving
- **Tooltips** — Anchored above bag buttons, item level display
- **Addon Support** — Questie nameplate icon positioning
